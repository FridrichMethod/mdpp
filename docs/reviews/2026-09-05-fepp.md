Baseline: `eecb097`. Scope: both workflows under `examples/fepp/`, their shared
preparation, mapping, launch, extraction, statistical-analysis and plotting
scripts, the 12 versioned ligand SDFs, and `tests/scripts/fepp/`.

## Conclusion

No additional normal-use coding or mathematical error was confirmed in this
subsystem. The existing workflow already addresses independent network gauges,
directed-edge signs, units, full node covariance, reference anchoring, repeat
heterogeneity and preparation provenance. No FEP+ production code was changed
solely to generate a finding. This is a review conclusion, not a claim that the
unperformed production simulations are scientifically converged.

| Area | Evidence and outcome |

| Receptor preparation | Builder applies the same declared His267 state to both receptors (HIE by default), compares atom connectivity and protonation signatures, and binds the comparison to launch provenance. HIE is explicitly a modeling assumption, not a measured protonation assignment. |
| Atom mapping | Extraction preserves paired core-atom correspondences while sorting them, distinguishes 1-based Suite indices from 0-based RDKit indices, and includes mapped-core element/bond changes in diagrams. Paired builds compare both edge sets and mapping fingerprints. |
| Vendor result extraction | Inspected installed Suite 2025-4 `fmp2excel.py`: `bennett_ddg_error` is exported from `bennett_ddg.unc`, while the edge value uses `.val`. Installed `graph.py` identifies `bennett_ddg` as the binding physical leg and combines its component legs and corrections. The adapter selects these raw fields rather than treating cycle-adjusted values as independent observations. |
| Network estimate | For incidence matrix `A` with the reference column removed and diagonal edge covariance `C`, implementation solves the whitened least-squares problem and computes `(A^T C^-1 A)^-1` using SVD. It inserts an exactly zero reference row/column in the full covariance. |
| Analytic test | Inconsistent unit-uncertainty triangle A→B=1, B→C=1, A→C=3 gives `(G_A,G_B,G_C)=(0,4/3,8/3)`, nonreference covariance `[[2/3,1/3],[1/3,2/3]]`, and chi-square `1/3` with one degree of freedom. Existing regression checks all of these. |
| Paired thermodynamics | The result is `(G_open,i-G_open,r)-(G_closed,i-G_closed,r)`. Independent state covariances add. An independent reference anchor contributes the full rank-one covariance `u_anchor^2 11^T`, not merely extra diagonal variance. |
| Units and gauge | Tests verify edge reversal, kcal/mol↔kJ/mol conversion, squared-unit covariance conversion, and reference-invariant pairwise contrasts. |
| Repeats | Independent repeats use inverse-variance pooling with an edgewise Birge scale bounded below by one. The chosen statistical model and approximate chi-square assumptions are explicit. Reused files, identities/seeds and mismatched protocols are rejected. |
| Run protocol | Launcher records force field, charge mode, water, ensemble, equilibration, production time, lambda count and salt. The declared muVT/SPC/OPLS4/5000 ps/12-window defaults are consistent with the published vendor interface; that consistency is not a sampling adequacy assessment. |

## Literature and best-practice assessment

[Mey et al., Best Practices for Alchemical Free Energy Calculations](https://doi.org/10.33011/livecoms.2.1.18378)
supports checking input chemistry, independent sampling, overlap and convergence
rather than interpreting internal estimator errors or cycle closure as complete
validation. The FEP+ example already documents these requirements. Three repeats
are a practical starting point, not a universal convergence criterion.

[Mobley, Chodera and Dill, The Confine-and-Release Method](https://pmc.ncbi.nlm.nih.gov/articles/PMC2562444/)
establishes why protein conformational restriction and its free-energy cost
matter. The existing README correctly distinguishes an initial structure from
a thermodynamic basin and asks for receptor CV/RMSD occupancy or justified
state-defining restraints and corrections. No basin stability is established
by the present repository inputs.

[Schrödinger's published FEPProtocol interface](https://learn.schrodinger.com/public/python_api/2026-3/api/schrodinger.application.transforms.fep.html)
documents the corresponding protocol fields/defaults and the distinction between
ordinary, core-hopping and charge-changing window counts. The actual installed
release inspected was 2025-4; the newer public page was used as supporting
interface documentation, not as evidence of a completed calculation or a reason
to upgrade dependencies.

## Unresolved scientific questions, already documented in the workflow

- No completed production `*_out.fmp` is versioned, so this review cannot assess
  overlap, equilibration, edge convergence, REST mixing or between-repeat
  agreement on real results.
- Verify receptor basin occupancy across the alchemical protocol. Unrestrained
  runs initialized open and closed need not measure distinct basin-conditioned
  quantities.
- Assess the intended LplA microstate, catalytic metal/cofactor and conserved
  water treatment. Their necessity is a system-specific scientific question;
  this review does not insert guessed ions or alter protonation arbitrarily.
- Inspect difficult graph edges, alternative plausible binding modes and the
  shared-pose assumption. Shared poses provide controlled inputs but are not
  evidence that all bound ensembles are sampled.
- Report diagonal edge-covariance and independent-state assumptions; shared
  force-field bias and other systematic error remain outside sampling error
  bars. A fixed-effect/Birge approach is one declared model, not proof that
  heterogeneous simulations estimate the same equilibrium quantity.
- OpenFE/FEP+ comparisons change several aspects of the physical model and
  preparation simultaneously. Differences cannot be attributed to the engine
  alone. Absolute open/closed preferences require an independent compatible
  anchor; state populations additionally require apo conformational information.
